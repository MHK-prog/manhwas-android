لطفاً برای کتاب‌ها یا مجموعه‌هایی که نامشان را در انتهای این متن می‌نویسم، اطلاعات قابل‌اعتماد جمع‌آوری کن و فقط یک JSON معتبر برگردان؛ بدون توضیح، کدبلاک، کامنت یا متن اضافه.

قالب خروجی:
{
  "books": [
    {
      "title": "نام کتاب",
      "author": "نام نویسنده یا هنرمند، اگر مشخص است",
      "genres": ["ژانر اول", "ژانر دوم"],
      "total": 120,
      "read": [],
      "interestRating": 0,
      "favorite": false
    }
  ]
}

قواعد:
- هر کتاب را یک شیء جداگانه در آرایهٔ books قرار بده.
- title الزامی است و باید رشته باشد.
- total تعداد کل فصل‌ها یا چپترهای منتشرشده است و باید عدد صحیح مثبت باشد. اگر تعداد دقیق پیدا نشد، مقدار 1 بگذار تا بعداً در برنامه اصلاحش کنم.
- genres آرایه‌ای از نام ژانرها باشد؛ اگر ژانری پیدا نشد، آرایهٔ خالی بگذار.
- read آرایهٔ شمارهٔ فصل‌هایی است که خوانده‌ام. چون این اطلاعات را نمی‌دانی، آن را خالی بگذار.
- interestRating عددی بین 0 تا 5 باشد و favorite مقدار true یا false داشته باشد. اگر سلیقهٔ من را نمی‌دانی، به‌ترتیب 0 و false بگذار.
- اطلاعات نامطمئن را حدس نزن؛ برای author نامعلوم رشتهٔ خالی بگذار.
- متن ژانرها و عنوان‌ها را داخل رشته‌های JSON قرار بده و ویرگول‌های JSON را درست بنویس.

نام کتاب‌ها و هر توضیحی که برای پیدا کردنشان لازم است:
۱. نام کتاب را اینجا بنویس
۲. نام کتاب بعدی را اینجا بنویس
