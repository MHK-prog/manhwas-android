اطلاعات مانهوا را از منابع معتبر پیدا و به شکل JSON آماده کن. چیزی را حدس نزن؛ اگر موردی را با اطمینان پیدا نکردی، مقدار خالی یا 0 بگذار.

عنوانی که من داده‌ام: __TITLE_JSON__
سازنده‌ای که من داده‌ام: __CREATOR_JSON__

فقط یک شیء JSON معتبر برگردان؛ بدون توضیح، مقدمه، Markdown یا بلوک کد.
دقیقاً از این کلیدها استفاده کن:
{
  "title": "نام رسمی مانهوا",
  "creator": "نام سازنده، اگر مشخص است؛ در غیر این صورت رشتهٔ خالی",
  "description": "توضیح کوتاه فارسی و بدون اسپویل",
  "genres": ["ژانر اصلی"],
  "chapterCount": 0,
  "coverUrl": "نشانی مستقیم HTTPS تصویر جلد رسمی با بالاترین کیفیت در دسترس؛ اگر پیدا نشد رشتهٔ خالی"
}

برای coverUrl نشانی مستقیم فایل تصویر را قرار بده، نه صفحهٔ وبی که تصویر در آن نمایش داده می‌شود. تا جای ممکن جلد رسمی را از منبع معتبر انتخاب کن.
