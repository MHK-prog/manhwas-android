برای مانهوا زیر اطلاعات مانهوا‌شناختی را پیدا و مرتب کن. اگر به اطلاعات مطمئن دسترسی نداری، آن را حدس نزن.

اطلاعاتی که من می‌دهم:
عنوان مانهوا: [عنوان]
نویسنده: [نام نویسنده، اگر می‌دانم]

فقط یک شیء JSON معتبر برگردان؛ بدون توضیح، مقدمه، Markdown یا ```.
دقیقاً از این نام فیلدها استفاده کن:
- title: نام مانهوا به صورت رشته
- author: نام نویسنده به صورت رشته
- description: توضیح کوتاه و بدون اسپویل به زبان فارسی
- genres: آرایه‌ای از ژانرهای اصلی مانهوا
- chapterCount: تعداد Chapterها به صورت عدد صحیح؛ اگر مطمئن نیستی 0

نمونهٔ قالب خروجی:
{
  "title": "",
  "author": "",
  "description": "",
  "genres": [],
  "chapterCount": 0
}
