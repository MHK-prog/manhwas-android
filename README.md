# مانهواخوان

اپلیکیشن بومی اندروید برای نگهداری فهرست، علامت‌زدن فصل‌های دیده‌شده و دریافت پیشنهاد بر اساس ژانرها و علایق.

## فهرست فصل‌ها

برای دیدن یا برداشتن تیک، روی چیپ فصل بزن. تعداد فصل‌های دیده‌شده بالای فهرست نمایش داده می‌شود و می‌توان فصل‌ها را از دکمهٔ افزودن به فهرست اضافه کرد.

در اجرای نخست، یک پوشه در انتخاب‌گر Android برگزین تا برنامه پوشهٔ `ManhwaReader` را برای جلدها بسازد. جلدها در پوشهٔ مخفی `.covers` نگهداری می‌شوند و فایل `.nomedia` مانع نمایش آن‌ها در گالری می‌شود. اطلاعات فهرست، فصل‌ها، امتیازها و علایق ژانرها در پایگاه دادهٔ SQLite داخلی برنامه ذخیره می‌شوند. فایل قدیمی `library.json` در اولین اجرا به پایگاه داده منتقل می‌شود.

## امتیاز و پیشنهادها

برای هر عنوان می‌توان از صفر تا پنج ستاره ثبت کرد؛ صفر یعنی هنوز امتیازی داده نشده است. امتیاز عنوان و پسند یا نپسندیدن ژانرها فقط روی پیشنهادها اثر می‌گذارند. ژانرها باید با حروف انگلیسی نوشته شوند و فهرست بر اساس زمان افزودن، از تازه‌ترین مورد به قدیمی‌ترین، مرتب می‌شود.

## پشتیبان‌گیری

از بخش تنظیمات می‌توان نسخهٔ پشتیبان JSON ساخت یا یک نسخهٔ پشتیبان را بازیابی کرد. JSON دیگر محل ذخیرهٔ روزمرهٔ اطلاعات نیست؛ پایگاه دادهٔ SQLite منبع اصلی اطلاعات برنامه است.

## ساخت APK

برای ساخت در PowerShell، JDK 17 و Android SDK Platform 36 لازم است:

```powershell
.\gradlew.bat :app:copyNamedReleaseApk
```

فایل خروجی با نامی مانند `Manhwa-Reader-Android-v1.4.34.apk` در `app/build/outputs/apk/manhwa-reader/` ساخته می‌شود. در مخزن `MHK-prog/manhwas-android`، workflow ساخت نسخهٔ امضاشده را با همین نام به‌عنوان Artifact منتشر می‌کند. برای امضا، secretهای `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD` باید در تنظیمات مخزن موجود باشند. راهنمای کلید در [ANDROID_UPDATE_SIGNING.md](ANDROID_UPDATE_SIGNING.md) است.

شناسهٔ بسته `com.mhkprog.manhwareader` و کمینهٔ نسخهٔ اندروید 6.0 (API 23) است.
